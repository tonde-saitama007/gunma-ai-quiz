# 群馬愛クイズ

茨城版の操作性を引き継いだ、非公式の無料クイズです。

- 群馬の30問から重複なしでランダム10問
- 4択・各問15秒・100点満点
- 正解8点＋早押しボーナス最大2点
- 5段階称号：群馬ルーキー／群馬探検家／群馬通／群馬愛の達人／上州マスター
- 結果ボタン：画像を保存する／シェア用リンクをコピー／もう一度挑戦
- 配色：山をイメージした緑と温かい茶色

出典は SOURCES.md を参照。問題番号はindex.html内QUESTIONSの配列順です。
